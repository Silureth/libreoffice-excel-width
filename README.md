# Excel Column Width for LibreOffice Calc

A small LibreOffice Calc extension that shows column widths **in the units
Excel uses**, live while you select or resize columns. You can also set a
width by typing an Excel value.

It is meant for people who generate `.xlsx` files with **NPOI / Apache POI /
openpyxl** (or anything else that writes Excel column widths) and check the
result in LibreOffice. Calc only shows widths in cm, inches or points.

```
┌ Excel column width ──────────────────┐
│ C                                    │
│ Excel 8.43   NPOI 2340   64 px       │
│                                      │
│ Set Excel: [ 8.43 ] [Apply] [Refresh]│
└──────────────────────────────────────┘
```

| Field     | Meaning                                                                   |
|-----------|---------------------------------------------------------------------------|
| **Excel** | The number Excel shows in *Format → Column Width* (characters)            |
| **NPOI**  | The value for `sheet.SetColumnWidth(col, n)`, in 1/256 of a character     |
| **px**    | Width in pixels at 96 DPI                                                 |

If you select several columns, the panel shows each one's width, or a single
line when they are all the same.

## Install

1. Download `ExcelColumnWidth.oxt` from the
   [latest release](../../releases/latest).
2. In LibreOffice, open **Tools → Extension Manager → Add…** and pick the file.
   Or, with LibreOffice closed:
   ```bash
   unopkg add ExcelColumnWidth.oxt
   ```
3. Restart LibreOffice.

> **Keep the file name `ExcelColumnWidth.oxt`.** The shortcut and buttons
> point to the extension by that name. If your browser saved it as
> `ExcelColumnWidth (1).oxt`, rename it before installing.

> **Ubuntu / Debian:** Python macros need an extra package:
> `sudo apt install libreoffice-script-provider-python`

## Use

Open a spreadsheet, then open or close the panel with any of these:

- **Ctrl+Shift+W**
- Tabbed UI: **Extension** tab → *Excel Column Width*
- Classic UI: **Tools → Add-Ons → Excel Column Width**, or the
  *Excel Column Width* toolbar (**View → Toolbars**)

To resize columns, select them, type an Excel width in **Set Excel** (`8.43`
or `8,43`) and press **Enter** or **Apply**.

## How the numbers are calculated

Excel measures column width in characters of the workbook's default font,
using the width of its widest digit (the *max digit width*, MDW). For
Calibri 11pt at 96 DPI, MDW = 7 px.

```
px          = Calc width (1/100 mm) / 2540 * 96
Excel (UI)  = (px − 5) / MDW            # Excel adds 5 px padding
NPOI value  = trunc(px * 256 / MDW)     # what is stored in the .xlsx × 256
```

So the default Excel column is `8.43` in the UI, `9.140625` in the file and
`2340` in NPOI. This is also why `SetColumnWidth(col, 20 * 256)` shows up in
Excel as about **19.29**, not 20.

### Limitations

- MDW is fixed at **7 px**, which is right for Calibri 11pt and Carlito,
  LibreOffice's metric-compatible substitute. If your workbooks use another
  default font or size, change `MDW_PX` at the top of
  [`src/python/excel_width.py`](src/python/excel_width.py).
- Calc converts Excel widths to 1/100 mm when it opens a file, so a value can
  be off by a pixel compared with Excel itself. Saving back to `.xlsx` can
  also change widths slightly.
- A new Calc document's default column is 85 px (Excel 11.43). Only files
  created by Excel or NPOI use Excel's 8.43 default.

## Build from source

Requires `python3` and `zip`.

```bash
./build.sh      # generates the icons and writes ExcelColumnWidth.oxt
unopkg add -f ExcelColumnWidth.oxt
```

Layout:

```
src/
├── description.xml           extension id, version, name
├── META-INF/manifest.xml     tells LibreOffice what each file is
├── python/excel_width.py     the panel (Python UNO macro)
├── Addons.xcu                menu entry, toolbar and Extension tab buttons
├── Accelerators.xcu          Ctrl+Shift+W in Calc
├── WindowState.xcu           toolbar name
└── icons/                    generated by make_icons.py
```

## Releasing

1. Bump `<version value="…"/>` in `src/description.xml`.
2. Commit, then tag and push:
   ```bash
   git tag v1.0.1
   git push origin main v1.0.1
   ```

The [release workflow](.github/workflows/release.yml) checks that the tag
matches the version in `description.xml`, builds `ExcelColumnWidth.oxt` and
attaches it to a new GitHub release.
